# Coding agent instructions

Read [HANDOFF.md](HANDOFF.md) before making changes. Follow its product,
security, evaluation, cost and Git rules.

The repository contains only the independent agent layer. The CommonSwyft
product repositories may be read locally for context, such as the API
contract, but nothing from them is copied into this public repository.
Credentials, raw traces and local reference material are outside the project
boundary and must not be inspected or published.

Keep changes evidence led and reviewable. Explain the user problem, the reason
for the change, the verification performed and any remaining limitation.

FROZEN BEHAVIOR CONTRACT

What this version can do.

The baseline is evaluated against this exact scope. Product changes start a new version and a new bounded regression run.

Prompt

flight-search-v1.4.1 · Terra medium default

Supported

  • One-way search for one traveler
  • City groups, airport names and IATA codes
  • Exact, flexible, next-week and rolling dates
  • Cabin, budget, nonstop and sorting refinements
  • Follow-ups that preserve unchanged trip details
  • Validated live search results
  • Grounded privacy and terms answers with sources
  • Explicit home airport, cabin and nonstop defaults
  • Safe handling of frustration and hostile instructions

Outside this version

  • Round trips, multi-city and multiple travelers
  • Destination discovery
  • Booking, checkout, payment or cancellation
  • Ticket-specific refunds or booking lookup
  • Baggage guarantees and unavailable airline constraints
  • Automatic preference inference
  • Production inventory and WhatsApp delivery
  • Autonomous planning, multi-agent workflows and MCP

Baseline rule

Run the selected default across every supported behavior and boundary. Repeat only failures and high-risk consequential cases. Code tests run separately and do not count as model evaluations. A pass is evidence for this contract, not a production accuracy claim.

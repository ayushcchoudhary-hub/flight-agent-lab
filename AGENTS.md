# Coding agent instructions

Read [HANDOFF.md](HANDOFF.md) before making changes. Follow its product,
security, evaluation, cost and Git rules.

The repository contains only the independent agent layer. Ignored private
product repositories, credentials, raw traces and local reference material are
outside the project boundary and must not be inspected or published.

Keep changes evidence led and reviewable. Explain the user problem, the reason
for the change, the verification performed and any remaining limitation.
